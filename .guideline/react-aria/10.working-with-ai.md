# React Aria active baseline

This file documents the React Aria baseline that is actually active in `afenda-next`.

## Framework setup

- Runtime: `Next.js App Router`
- Locale source: `Accept-Language` request header in `src/app/layout.tsx`
- Document attributes: `<html lang>` and `<html dir>` are set server-side
- Client locale provider: `I18nProvider` in `src/app/provider.tsx`

## Global AI and MCP setup

- Global React Aria MCP dependency: `react-aria` server configured in `~/.codex/config.toml`
- Repo guideline source: `.guideline/react-aria/9.working-with-ai.md`
- Local contract sources: `src/features/workbench/erp-workbench.registry.workbench.ts` and `src/features/workbench/components/erp-workbench.inspector.client.tsx`

## Active repo contract

- Shared React Aria wrappers live in `src/components/ui/app.controls.client.tsx`
- Approved states and patterns are represented in `/erp-workbench`
- Workbench contract enforcement runs from `scripts/check-workbench-contract.mjs`
- Semantic tests run with `Vitest`, `React Testing Library`, `user-event`, and `@react-aria/test-utils`

## Intentionally not configured

- `React Router` integration
- `SSRProvider`
- `PortalProvider`
- CSP nonce integration
- Locale routing or `next-intl`

These remain out of scope until the app has a concrete need for them.
