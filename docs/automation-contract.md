# Documentation Automation Contract

## Generated README Ownership

README files inside declared automation margins are generated by `pnpm docs:generate` and must not be edited manually. Manual edits belong in source docs outside the generated README margin.

Every generated README must include the generated marker, ownership warning, and generated-area note. Standard generated README indexes use:

```md
<!-- @afenda-generated-readme -->

# Title

> [!WARNING]
> This README is generated by `pnpm docs:generate` inside a declared Afenda README automation margin.
> Do not edit this file manually. Manual changes will be overwritten.
> Update the source files, source markdown files, ADRs, or guideline documents instead.

**Generated area:** declared README automation margin.

**Out of scope:** package README files and unconfigured module README files are not generated for this single-application repo shape.
```

The root `README.md` is the D3 exception: it is still generated, but it also includes a source-template note pointing to `docs/source/root-readme.md`.

## Manual Source Documentation

Manual documentation lives in named markdown files, not generated README files inside declared automation margins.

Manual source docs include:

- `docs/architecture.md`
- `docs/atc.md`
- `docs/adr/*.md`
- `docs/source/root-readme.md`
- `.guideline/**/*.md` except generated `README.md` files
- source files under configured D2 source margins

## D1 Generated README Matrix

| Source                  | Output                            | Purpose                    |
| ----------------------- | --------------------------------- | -------------------------- |
| `docs`                  | `docs/README.md`                  | Project docs index         |
| `docs/adr`              | `docs/adr/README.md`              | ADR index                  |
| `.guideline`            | `.guideline/README.md`            | Guideline index            |
| `.guideline/nextjs`     | `.guideline/nextjs/README.md`     | Next.js guideline index    |
| `.guideline/react-aria` | `.guideline/react-aria/README.md` | React Aria guideline index |

## D2 Generated README Matrix

| Source                   | Output                             | Purpose                   |
| ------------------------ | ---------------------------------- | ------------------------- |
| `src/components`         | `src/components/README.md`         | Shared component index    |
| `src/components/ui-governance`      | `src/components/ui-governance/README.md`      | Shared UI primitive index |

D2 source indexes are non-recursive. Source root indexes list immediate child source groups. Source module indexes list immediate child source groups and immediate source files.

## D3 Generated README Matrix

| Source                       | Output      | Purpose                |
| ---------------------------- | ----------- | ---------------------- |
| `docs/source/root-readme.md` | `README.md` | Root repository README |

Root README generation is template-backed. Manual root README prose belongs in `docs/source/root-readme.md`; generated navigation belongs in the generator.

## Deferred Work

Package/module README generation is not applicable for the current single-application repo shape. It must not be added unless explicit package roots are introduced through a later ADR.

## D4 Documentation Contract Validation

`pnpm check:docs` validates generated README drift plus source documentation structure without generating files.

The D4 validator checks:

- Generated README outputs are present and up to date with the current generator and source template.
- ADR filename, heading, metadata, status vocabulary, required sections, and contiguous numbering.
- ATC heading, snapshot date, scope line, and required A-E sections.

It does not validate prose quality, business correctness, or semantic agreement between ADRs.

## Verification

Run:

```bash
node --check scripts/repo.docs-index.generator.automation.mjs
node --check scripts/repo.docs-contract.check.automation.mjs
pnpm docs:generate
pnpm exec prettier --check README.md docs/**/*.md .guideline/**/*.md src/**/*.md
pnpm check:architecture
pnpm check:docs
git diff --check
```
